# The fixture ledger — one line per fixture set, with the state the suite expects.
#
#   PASS     the fixture must run and match its golden output (and messages, for legacy)
#   PENDING  the fixture is not yet ported; the suite expects it to fail
#   SKIPPED  out of scope, with the reason; never run
#   QUARANTINED  in scope, but the golden itself is wrong — see design/08-fixture-audit.md
#
# The ledger is a ratchet. A PENDING fixture that starts passing fails the build until
# it is promoted here, so every phase of the port has to move a number on purpose.
# See ../../../../design/07-engine-port-plan.md.
